# Exercise 0.6: New note in SPA

note over browser:
User writes a note and submits the form.
JavaScript prevents the normal form submission.
end note

note over browser:
The new note is added to the list on the page immediately.
end note

browser->server: HTTP POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
note over browser:
Request body contains the note as JSON.
Content-Type: application/json
end note

note over server:
The server saves the new note.
end note
server-->browser: HTTP 201 Created

note over browser:
The page does not reload.
No more requests are needed.
end note
